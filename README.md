# Lucky Carpet Cleaning

Welcome to the **Lucky Carpet Cleaning** website project.  
This repository contains the source code and documentation for the company’s official site.

---

## 📌 Overview

The site is designed to showcase carpet cleaning services, provide contact information, and allow customers to easily request quotes or book appointments.  
It features a responsive design, SEO‑friendly structure, and modern frontend tooling.

---

## 🚀 Tech Stack

- **Build Tool:** [Vite](https://vitejs.dev/)
- **Language:** JavaScript (ES6+)
- **Styling:** CSS3 (with responsive layout)
- **Deployment:** Static hosting

---

## 📂 Project Structure

```
lucky-carpet-cleaning/
├── dist/ # Dist The optimized files
├── public/ # Static assets (images, icons, favicon)
├── server/ # PHPMailer
├── src/ # Source code
│ ├── styles.css/ # Page views
│ └── main.js # Entry point
├── index.html # Root HTML file
├── package.json # Dependencies and scripts
└── README.md # Project documentation
```

---

## 🛠️ Setup & Development

1. **Install dependencies**
   ```bash
   npm install
   ```

## Run development server

2. npm run

## Build for production

3. npm run build

**The optimized files will be generated in the dist/ folder.**
